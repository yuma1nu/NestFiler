# Nest Filer — simplified icon proposals

2026-11-15。前回の立体・発光案を簡素化した比較用の案。アプリへの適用は行っていない。

- A: N＋フォルダのタブ。最小限の形で名称を示す。
- B: フォルダの中にフォルダ。Nest／入れ子の意味を示す。
- C: フォルダの左右を分割。2ペインの意味を示す。

最終比較画像: [comparison.png](comparison.png)。白背景の比較用画像で、個別の透過アイコンやICOではない。

生成方法: built-in `image_gen.imagegen`。既存案を参照した簡素化案を生成後、塗りのムラが出た案を修正し、白背景の比較シートへ再描画した。CLI/APIフォールバックは使用していない。中間のムラのある案は最終案として保存していない。

正確な生成プロンプトと参照元は [prompts.json](prompts.json) に記録。前回案を上書きせず、別ディレクトリに保存した。
